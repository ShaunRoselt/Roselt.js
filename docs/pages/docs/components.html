Components

Roselt.js resolves components from components/ and infers the tag from the filename.

Components are standard custom elements with a lightweight authoring shape. Roselt.js discovers the tags present in the shell or rendered page, loads the matching file when needed, and gives each element a few small helper methods for common DOM work.

File name to tag name

A tag such as <save-button> maps to components/save-button.js. Roselt.js loads that file the first time it sees the tag.

components/
  save-button.js
  site-header.js
  admin-sidebar.js

Author a component with normal DOM APIs

The preferred shape is Roselt.defineComponent(function () { ... }), though a single object definition works too. Inside the definition, this is the actual element instance, so you can use normal properties like innerHTML, dataset, classList, and the usual DOM methods.

Roselt.defineComponent(function () {
  this.render = () => `
    <button type="button">${this.innerHTML || "Save"}</button>
  `;

  this.on("click", "button", () => {
    alert("Saved");
  });
});

Because the file is named save-button.js, Roselt.js registers it as <save-button> automatically.

Available definition hooks

Property Use it for
setup() Run one-time initialization for object-style component definitions before the first render.
render() Return the HTML that Roselt.js should place into the component.
connected() and disconnected() Run setup and teardown when the element enters or leaves the DOM.
observedAttributes and attributeChanged() React to attribute changes and rerender when component inputs change.
autoRender Disable the automatic rerender after an observed attribute changes by setting it to false.
shadow Shadow DOM is the default. Set this to false when the component should render into light DOM instead of a shadow root.

Built-in element helpers

Helper Use it for
this.on(type, selector?, handler, options?) Attach direct or delegated event listeners against the component render root.
this.emit(type, detail?, options?) Dispatch a bubbling custom event from the component element.
this.requestRender() Force the component to rerender immediately.
this.root Read the active render root, which is the shadow root by default or the element itself when shadow is false.

Shell components and page components use the same system

A component in the routed page and a component in the outer shell are both loaded the same way. The only difference is where you place the tag in HTML.

<site-header></site-header>
<main>
  <roselt page="home" navigate></roselt>
</main>
<site-footer></site-footer>
Keep component names hyphenated

Roselt.js still uses the browser custom element model, so component filenames and tags need a hyphen such as save-button or site-header.

Preferred and legacy registration forms

The preferred API is Roselt.defineComponent(definition) with the tag inferred from the filename. Roselt.js still accepts Roselt.defineComponent("save-button", definition) for backward compatibility.
